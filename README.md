# Paradise Nursery Shopping Application

A small online plant shop where you can browse houseplants, add them to a cart, adjust quantities, and see your total update as you shop.

## Main features

- Three plant collections with locally stored product artwork
- Shared navigation between Home, Plants, and Cart
- Redux-powered cart with quantity controls, item removal, and a live item count
- Responsive layout for smaller screens

## Technologies

React, React Router, Redux Toolkit, React Redux, and Vite.

## Run locally

```bash
npm install
npm run dev
```

To create a production build, run `npm run build`.
